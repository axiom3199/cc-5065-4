# DirGuide · 间接光方向引导实验台

空间区域在线学习方向分布的 CPU 路径追踪实验室。引导表只产生提议方向；
每个估计都除以真实混合概率 `p = λ·g + (1−λ)·p_BSDF`，缓存观察永远不会
直接变成像素能量。

## 图形入口（方向引导的主入口）

```bash
python3 run_ui.py --port 8765
# 浏览器打开 http://127.0.0.1:8765/
```

窗口内的方向引导入口：

| 入口 | 位置 | 作用 |
| --- | --- | --- |
| 引导策略选择 | 左侧「引导策略」下拉 | 手动切换 纯BSDF / 在线引导 / 移灯后保留旧表 / 衰减 / 重建，渲染不中断 |
| λ、η 等滑杆 | 左侧控件区 | 调整引导混合比、均匀底质量、衰减半衰期等 |
| 单步 / 连续渲染 | 左侧按钮区 | 推进采样；中栏「照明收敛」图实时显示 RMSE 与平均亮度收敛 |
| 移动光源 A↔B | 左侧按钮区 | 按当前策略处理旧方向表（保留/衰减/重建） |
| 方向分布检查器 | 点击渲染图任意位置 | 右栏显示该空间区域学到的方向分布、熵、KL、最小混合 pdf |
| 分布版本保存/载入 | 左侧按钮 + 右栏下拉 | 保存当前方向表版本，或载入历史版本对照检查 |
| 回归样例 | 左侧「验收与回归」 | 一键载入移灯回归场景（真实训练后移灯），随后手动切换策略观察照明收敛与方向分布 |
| 运行统计正确性验收 | 左侧「验收与回归」 | 在解析小场景上真实重算验收，结果在下方「统计验收」页 |
| 统计验收 | 底部结果区标签页 | 均值置信区间 + 执行证据（试验均值）、零支持反例、注入错误密度捕获情况 |
| 等预算实验结果 | 底部结果区标签页 | 固定光 / 移灯研究的 RMSE、relMSE 曲线与误差热图 |

界面上的每个按钮都调用真实的方向引导实现（`RenderSession` /
`DirectionGuide` / `dirguide.acceptance`），不用固定数据冒充照明收敛或
方向分布。

## 命令行（仅辅助）

图形界面是主入口；以下命令只是辅助手段，产物会被界面读取展示：

```bash
python3 run_experiments.py --quick        # 快速等预算实验 + 参考图
python3 run_experiments.py                # 完整研究（并行，数分钟）
python3 run_experiments.py --acceptance   # 只跑统计验收套件
python3 -m dirguide.acceptance            # 同上（快速档）
python3 -m pytest tests/                  # 全部测试（含验收集）
```

## 统计正确性验收（`dirguide/acceptance.py`）

验收集与测试一同入库（`tests/test_acceptance.py`），要点：

- **解析小场景**：单个着色点 + 球冠灯，反射辐射有闭式解
  `L_o = ρ·L_e·sin²α·max(n·ω₀,0)`，期望值独立推导，与采样器无关。
- **分布与图像测试**：混合 pdf 归一化、采样直方图对精确 bin 质量的
  卡方检验、小图像逐像素均值对照解析图。
- **中途开灯夹具**：训练中途打开一盏小灯，把旧方向表连同生成它的样本
  送回采样器；旧表仍有微小探索概率（η>0）时用多次独立区间检查能量。
- **零支持反例**：关掉探索分支（η=0、λ=1）完全漏掉新灯方向时，夹具
  要求重建提议（`verdict=rebuild_required`），不会把更多轮次的稳定
  低估判成收敛；误用旧密度后最先异常的光源分量存入
  `outputs/acceptance/first_anomalous_component.json`。
- **偏差/方差分离断言**：固定采样预算、多次独立试验，均值置信区间与
  方差比分别断言；并与独立无引导估计做多轮区间核查。
- **受控错误必须暴露**：注入陈旧密度 / 缩放密度后，均值置信区间必须
  失败；评估数据与学习记录严格分开。
- 每条均值置信区间都附带计算它所用的试验均值（执行证据），不允许
  伪报。
